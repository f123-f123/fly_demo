# DNb05 因果消融与局部奖励可塑性实验

更新日期：2026-09-21

## 1. DNb05 出站消融

### 问题

阶段 13 的全下降神经元扫描发现 DNb05 对降温和潮湿刺激有响应。本实验进一步检验：DNb05 是否是这些感觉信号传播到其余下降神经元的必要瓶颈。

### 方法

- 条件：Baseline、Sham 1×、双侧 DNb05 出站权重 0×。
- 干预范围：2 个 DNb05 的 2,243 条出站连接，仅在进程内修改。
- 训练种子：9101、9203、9307；留出测试种子：10101、10203；每个种子 8 个并行个体。
- 读出：仅使用训练集选择的 50 个最强下降神经元特征，并明确排除 DNb05 自身。
- 必要性标准：0× 相对 Baseline 的留出 AUC 或准确率下降至少 0.20。

### 结果

Baseline 的留出 AUC 为：升温 1.000、降温 1.000、干燥 0.922、潮湿 1.000。Sham 与 Baseline 完全等效。0× 后对应 AUC 为 0.992、1.000、0.969、1.000；所有通道的 AUC 或准确率下降均小于 0.20。

因此，本实验质量门通过，但“DNb05 是当前温湿度下降表征的必要瓶颈”这一假设未获支持。阴性结果不代表 DNb05 在真实果蝇或其他刺激协议中没有运动功能，也不授权把它接入闭环运动。

复现：

```powershell
conda run -n flybrain python scripts\run_dnb05_ablation.py --device cuda --batch 8 --train-seeds 9101,9203,9307 --test-seeds 10101,10203
```

机器结果：`config/experiments/dnb05_ablation.json`。

## 2. LC10a 出站突触的局部奖励可塑性

### 问题

检验一个受限、可审计的奖励调制时序规则，能否在 Decoder 冻结时提高 LC10a 刺激引起的双侧 DNa02 响应和转向幅度。

### 方法

- 可塑范围：275 个 LC10a 的 39,282 条出站突触。
- 规则：单步 pre-before-post 共活动减去 0.5 倍 post-before-pre 共活动，回合结束后乘奖励更新。
- 条件：Frozen、Sham reward、平衡随机奖励、与方向正确性相关的奖励。
- 训练：4 个 epoch，每批 8 个个体；留出测试种子 12101、12203、12307。
- 约束：权重倍率限制为 0.5–1.5；Decoder 全程冻结；所有权重只存在于内存。
- 通过标准：相关奖励需同时提高转向和同侧 DNa02，并以预设余量优于随机奖励；全脑活动不得饱和。

### 结果

相关奖励把平均权重倍率推至 1.149，96.3% 的选中突触发生变化。总体转向幅度从 Frozen 的 0.341 增至 0.375，同侧 DNa02 从 2.083 增至 2.271 Hz，全脑活动保持稳定。

但变化不具备稳健的双侧一致性：左侧响应增强，右侧没有改善；相关奖励与随机奖励的转向差仅 0.0268，低于预设 0.03；相对 Frozen 的转向和 DNa02 增量也未达到预设门槛。因此 `experiment_passed = false`。

结论是：这个简单局部规则能改变权重并产生局部偏移，但不能据此声称网络学会了双侧视觉转向。当前不进入联合训练或实时闭环学习。若继续可塑性研究，应先定义有生物学依据的局部回路和奖励来源，例如 KC–MBON–DAN，而不是调低当前门槛以制造阳性结果。

复现：

```powershell
conda run -n flybrain python scripts\run_reward_plasticity.py --device cuda --batch 8 --epochs 4 --train-seed 11101 --test-seeds 12101,12203,12307
```

机器结果：`config/experiments/reward_plasticity.json`。

## 3. 数据完整性与边界

- 两项实验前后 `weights.npz` SHA-256 均为 `c29919aa44069a271b1ee978abe05fa9bf6e45e4ba3e436e92b624ef1b5be40c`。
- DNb05 消融不阻止 DNb05 自身放电，只去除其对下游的出站影响。
- 奖励是实验者定义的任务信号，不是当前 FlyBrain 中已验证的多巴胺奖励通路。
- 两项实验均未增加新的 Decoder 输入，也未把温度、湿度或 DNb05 接入运动。
